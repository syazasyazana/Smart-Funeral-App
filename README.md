# Smart-Funeral-App

This project presents a thoughtful digital solution called Eternal Ease, a Smart Funeral Application aimed at easing the burden of funeral planning and memorialization. It offers features such as user authentication, profile management, legacy video messaging, digital memorial walls, event planning, and yearly anniversary commemorations, with integration of technologies like AR, VR, and AI. The app targets grieving families and funeral planners, ensuring secure, user-friendly, and emotionally supportive experiences during difficult times.

Focused mainly to interface design and app functionality.
